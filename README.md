## ✨ Key Features

- **Modern UI/UX**: Clean, minimal design with glassmorphism effects and subtle animations.
- **Fully Responsive**: Optimized for all screen sizes, from mobile devices to large desktops.
- **Dark/Light Mode Support**: Respects system-level color preferences for a comfortable viewing experience.
- **SEO Optimized**: Advanced meta tags and JSON-LD Schema Markup (Organization & WebSite) for superior Google Search visibility.
- **Legal Compliance**: Includes dedicated Privacy Policy and Terms of Service pages.
- **Performance**: Lightweight, vanilla implementation with Inter font family for maximum speed and readability.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Modern features like Grid, Flexbox, and CSS Variables).
- **Icons**: Hand-crafted SVG icons for performance and scalability.
- **Deployment**: Optimized for fast static hosting environments.
